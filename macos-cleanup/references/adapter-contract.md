# Adapter and Action Contract

This is the implementation contract for the next DAG increment, not approval to clean the development Mac. Python 3.10+ and standard library only. All tests use temporary local fixtures and mocked owner commands.

## Modules and ownership

- `cleanup_contract.py`: strict plan parsing, canonical digest and filesystem identity.
- `cache_adapters.py`: trusted built-in owner discovery, version and command semantics.
- `cloud_inventory.py`: bounded guarded metadata-only item inventory, no eviction.
- `cleanup_executor.py`: approval binding, preflight, journal and sequential dispatch.
- `cleanup_actions.py`: CLI integration owned by the main agent after dependencies pass.

No adapter owns `audit_runtime.py` or `audit_all.py`. Existing audit JSONL is never execution authority.

## Shared Python API

`cleanup_contract.py` exports:

```python
class PlanError(ValueError): ...
def capture_target(path: str, *, home: str | None = None,
                   max_entries: int = 10000, timeout: float = 10.0) -> dict: ...
def make_plan(adapter: str, target: str, executable: str, version: str,
              *, home: str | None = None, now: float | None = None,
              ttl_seconds: int = 900) -> dict: ...
def validate_plan(plan: object, *, now: float | None = None) -> dict: ...
def plan_digest(plan: dict) -> str: ...
def target_unchanged(plan: dict) -> bool: ...
def load_plan(path: str) -> dict: ...
def write_private_json(path: str, value: dict) -> None: ...
```

Plan schema (extra fields rejected):

```json
{
  "schema_version": 1,
  "adapter": "uv",
  "action": "uv-cache-prune",
  "target": "/absolute/local/configured/cache",
  "home": "/absolute/home",
  "target_state": {},
  "executable": "/absolute/resolved/tool",
  "executable_state": {},
  "version": "installed version string",
  "created_at": 0.0,
  "expires_at": 900.0,
  "scope": "owner-managed-dynamic-cache",
  "risk": "Owner-managed cache maintenance may remove shared cache entries; re-download/rebuild required. Scope is dynamic, not a fixed file deletion list.",
  "estimated_reclaimable_bytes": null
}
```

Allowed adapter/action pairs are initially `uv`/`uv-cache-prune` and `go`/`go-build-cache-clean`. All other adapters are review-only. Plan JSON cannot specify argv, environment, arbitrary scripts, hooks or deletion patterns. `target_state` and `executable_state` are generated by trusted capture logic, not interpreted as commands. The fixed risk/scope strings above are part of the digest.

`capture_target` is metadata-only and establishes native no-hydration protection before filesystem access. Fail closed for root/home aliases, unsafe ancestry, symlinks within cache, crossed mounts, dataless entries, unreadable or incomplete traversal, excessive entries, or target/ancestor changes during capture. Compare identities, not only path strings; account for macOS root-owned aliases/firmlinks. Return deterministic metadata fingerprint, allocated/logical counts and root/ancestor identity (no content hash). Failures mean review-only, not zero-size. This deliberately strict initial implementation may block common symlink-containing caches; report that, do not silently weaken safety.

Known cloud namespaces beneath the home directory (File Provider, iCloud and standard legacy provider roots) are rejected as cache action targets even when fully materialized. A configured cache path does not authorize namespace deletion from a cloud provider. Arbitrary custom legacy sync locations still require independent ownership/sync review; standard-path exclusion does not prove a folder can never be synchronized by another client.

Executable identity is file metadata and must be recaptured before dispatch. Installed Homebrew executables are often symlinks: resolve the executable once to a regular owned file during preparation, bind the resolved identity, and block if discovery/version changes later. This is not a security boundary against a malicious same-user process.

`make_plan` captures state but does not approve or execute. Validation rejects unknown keys, unsupported action pairs, nonfinite timestamps, TTL above 900 seconds, future/stale plans, path/control injection, executable/root/home misuse and malformed identity shapes. Stable SHA-256 over canonical JSON binds the entire reviewed plan. It is an integrity/consent binding, not a cryptographic signature proving a human clicked a UI.

Saved plans are private execution inputs, distinct from redacted public audit reports. `write_private_json` uses exclusive creation at mode 0600, safe ancestry with no user symlinks, and refuses an existing destination; never changes someone else's file permissions or overwrites it. `load_plan` uses no-follow open, bounded size, regular-file/current-user ownership/private-permission checks, duplicate/nonfinite JSON rejection and strict validation. Root-owned standard Darwin aliases may be accepted explicitly. Tests for private-file collisions, links, permissions, malformed/replayed/stale plans belong to the contract/executor rather than only mocked CLI tests.

## Cache adapter API

```python
def discover(adapter: str, *, probe=None) -> dict: ...
def prepare(adapter: str, *, probe=None) -> dict: ...
def preflight(plan: dict, *, probe=None) -> dict: ...
def build_command(plan: dict) -> tuple[list[str], dict[str, str]]: ...
```

`probe(argv, *, env=None)` is an injectable bounded read-only command callback returning a dict with `returncode`, `stdout`, `stderr`, `outcome`. Default probes use guarded `audit_runtime.run_command` and temporary private files, sanitize errors and never invoke cleanup/verify/prune during discovery. No tests invoke real installed owner commands.

`discover` returns JSON-serializable review evidence with `adapter`, `status`, `executable`, `version`, `target`, `owner_activity` (`idle`/`active`/`unknown`), `supported` (bool), `reasons` (sanitized strings), `risk`, `estimated_reclaimable_bytes` (always null initially). It never returns actionable=true. Check documented feature support, version syntax, configured cache and known writers; unknown/active block preparation. `prepare` calls `make_plan` only for uv/go with reviewed feature support and complete idle evidence. Unsupported versions/link modes stay review-only. npm/Homebrew return reviews, not plans.

`preflight` returns `{"ok": bool, "reasons": [...], "evidence": {...}}`, freshly rediscovering the same executable, version, configured root and writer state. Must not run a mutation. Dynamic owner cache scope and link/centralized environment risks are disclosed. Known writer checks complement owner locks, not replace them.

`build_command` is a pure trusted allowlist: validates the plan, builds absolute executable argv and a complete environment, never copies command text from input. Do not merge ambient variables back into this environment. uv prune has no force; uses bounded lock timeout and explicit cache root. Go clears inherited GOFLAGS/GOCACHEPROG and toolchain/workspace overrides, cleaning only explicit GOCACHE, not modules/fuzz. Unknown versions/capabilities block. `prepare` returns only a valid plan or raises sanitized AdapterError, never a review-evidence dict.

## Executor API

```python
def execute(plan: dict, *, confirmed_digest: str, journal_dir: str,
            now: float | None = None) -> dict: ...
```

Executions are one plan at a time and invoked only after an exact human choice. Validate digest, TTL, supported action and absolute paths; establish guard; run fresh adapter preflight; recapture target and executable identity; compare capacity samples on the same volume; block material continuing drift. No arbitrary cleanup callbacks or registry loaded from disk in production.

Reserve a single-use plan-digest journal BEFORE owner mutation with exclusive creation and private no-symlink storage. Replay, including an interrupted previous attempt, is blocked pending reconciliation. Do not retry automatically. Use only trusted `build_command` through the runtime with bounded timeout and explicit env; no shell, rm, sudo, process termination of user apps or cloud eviction.

Persist started and terminal outcomes (`BLOCKED`, `EXECUTED`, `PARTIAL`, `UNCHANGED`) with before/after target/capacity/version evidence. Return `EXECUTED` only when command success and postcheck support it; empty/unchanged target is distinct; timeout/cancel is PARTIAL even if some space is freed. Raw owner output is transient/private and never copied to public journal. Failed postcheck cannot be success. Integrity digest cannot eliminate TOCTOU with an uncooperative writer: scope/locks and conservative preflight still required.

## Cloud metadata API

```python
def inventory(root: str, *, max_entries: int = 1000,
              max_depth: int = 3, timeout: float = 10.0) -> dict: ...
```

Establish guard before touching root. Use lstat/scandir metadata only, no payload open/hash/preview/xattr dumping or brctl eviction/status content. Skip dataless directories. Do not follow symlinks/mounts, exclude duplicate hardlinks from totals, retain partial records and labelled lower bounds. Unknown sync/pin/provider eviction remains non-actionable. Public item IDs use a fresh per-inventory HMAC secret; they are not stable across runs and cannot be used as executable targets. Do not expose private names/accounts. Root inspection is not consent to eviction.
