# 01: Предпросмотр встреч проекта из OBS

Status: resolved
Blocked by: None (can start immediately)

## What to build

По запросу на импорт встреч пользователь получает предпросмотр событий явно привязанного календаря и соответствующих записей OBS с основаниями сопоставления. Никакие исходники и транскрипты не изменяются. Это первый работающий сквозной сценарий расширения meeting-transcript, не отдельный импортёр.

## Acceptance criteria

- [x] Версионированные глобальные TOML-настройки задают источники и формат имён; проектные — провайдер календаря, идентификаторы календарей, часовой пояс, относительное место импорта и выбранные источники. Учётные данные остаются в существующей календарной интеграции.
- [x] Приоритет параметров: явный запрос, настройки проекта, глобальные настройки. Разовый запрос не сохраняет изменение настроек без отдельного разрешения.
- [x] Отсутствующие календарная привязка, часовой пояс и начальная дата первого периода запрашиваются, а не угадываются. Примеры провайдера и часового пояса из обсуждения не считаются выбранными значениями.
- [x] Конец периода фиксируется на старте; ещё не закончившиеся события откладываются. Нет фонового сканирования.
- [x] Предпросмотр показывает верхнеуровневые записи OBS, календарные события и доступные доказательства соответствия. Наличие события не означает наличие записи.
- [x] Сопоставление использует проверенные доступные признаки; ближайшее время само по себе не считается достаточным. Неоднозначные случаи требуют уточнения.
- [x] Конкретные временные допуски и правила уверенности описаны и проверены на представительных примерах; произвольный порог не выдаётся за согласованное требование.
- [x] Устойчивая идентичность события учитывает календарь и отдельные повторяющиеся экземпляры; одинаковые названия не склеивают встречи.
- [x] Публичный сценарий проверен на синтетическом календаре и временном источнике: настройки, отсутствующие параметры, явный источник, уникальные и неоднозначные кандидаты, отсутствующая запись, незавершённое событие и отсутствие файловых изменений.
- [x] Инструкции meeting-transcript описывают новый предпросмотр; существующий импорт из явного канонического источника сохраняет поведение и регрессионные тесты.

## Scope and safety

Автоматизированные проверки используют временные источники. Настройка реального календаря, изменение пользовательской конфигурации и мутации реальных записей требуют соответствующего пользовательского разрешения.

## Comments

### Verification

Публичный сценарий реализован; полная серия meeting-transcript: 50 тестов OK (41 календарный и 9 прежних). Одобрённый вложенный TOML проверен отдельными регрессиями. Автоматическое сопоставление требует доказательств; неизвестные реальные источники не становятся проверенными по одному имени. Подробности и ограничения сохранены в отчёте реализации этой функциональности.
