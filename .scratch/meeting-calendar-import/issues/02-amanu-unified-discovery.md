# 02: Обнаружение Amanu и объединение источников

Status: resolved
Blocked by: 01

## What to build

В существующем предпросмотре пользователь видит пакеты Amanu вместе с OBS. Источники одного календарного события группируются в одну встречу с готовностью транскрипта, доказательствами соответствия и предупреждениями о безопасности.

## Acceptance criteria

- [x] Проверена техническая структура метаданных Amanu: семантика времени, явность часового пояса, доступность идентификаторов событий и признаки обработки. Непроверенные поля не предполагаются существующими.
- [x] Ошибки чтения метаданных отражаются как неизвестность или недоступность, а не как отсутствие встречи или доказанное завершение обработки.
- [x] Обнаруживаются верхнеуровневые пакеты Amanu; внутренние артефакты не изменяются. Доступные технические признаки используются в общем календарном сопоставлении.
- [x] Предпросмотр различает готовый транскрипт, отсутствие транскрипта и неустановленную готовность.
- [x] Наличие маркера транскрибирования само по себе не доказывает активность; устаревший маркер учитывается отдельным сценарием. При невозможности установить безопасность пакет отмечается как небезопасный для переименования.
- [x] OBS и Amanu для одного подтверждённого события показаны как одна встреча с несколькими исходниками. Неоднозначные связи требуют уточнения и не склеиваются автоматически.
- [x] Публичные проверки покрывают совместные и раздельные источники, недоступные метаданные, спорное время, готовность транскрипта и активную либо неопределённую обработку.
- [x] Документирован контракт источника Amanu и поведение при неполных данных; предпросмотр по-прежнему не меняет исходники и транскрипты.

## Scope and safety

Изначально чтение метаданных было заблокировано Resource deadlock avoided. Пользователь загрузил файлы локально; затем структура всех 32 пакетов проверена только чтением. Тестовые мутации выполняются исключительно на синтетических пакетах.

## Comments

### Implementation qualification

Блокировка снята. Проверены реальные структуры всех 32 пакетов и 5 879 сегментов. Нативный адаптер читает UTC-метаданные, JSON-сегменты, варианты speaker-map и согласованную запись завершения в логе, формирует кандидатов по интервалу с обязательным явным сопоставлением и объединяет их с OBS. Метаданные OBS читаются ограниченным ffprobe без декодирования. Нечитаемые, неизвестные и неподдержанные пакеты остаются pending. Нативная готовность транскрипта НЕ даёт права переименовывать источник: неизвестное idle блокирует операцию даже при подтверждении. Финальная проверка: 66 тестов OK; независимая read-only конвертация 32/32 реальных пакетов успешна; исходники не менялись.
